## 1. Executive Summary

P4.5 exposes the classified attempt data from P4.4.3/P4.4.4 through two
read-only endpoints behind the existing gateway-key middleware:

- `GET /api/failures` — paginated, filterable list of non-success attempts
  (filters: class / provider / virtual model / time window).
- `GET /api/failures/summary` — totals, per-provider and per-class
  breakdowns, and fixed-width time buckets.

No dashboard UI; no write capability; same isolation contract as the trace
query API (reads persisted rows only, never participates in routing).

## 3. Notable Bug Caught During Verification

The summary endpoint returned a silent fiber 500: bucket timestamps were
double-scaled (`strftime('%s')/?*?` in SQL **and** another `*bucketSecs` in
Go) producing year-1225403 timestamps that broke `time.Time.MarshalJSON`.
Diagnosed via temporary fiber ErrorHandler logging; fixed to
`time.Unix(b.Bucket, 0)` and covered by the aggregation test asserting
bucket coverage of all failures.
